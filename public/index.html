Under the hood

Why the photo upload is the hard part

A file upload box is the widest door into a server most apps have. This one assumes every upload is hostile until proven otherwise: the declared file type is never trusted, the bytes are checked against their real signature, the image is decoded and rebuilt from scratch (which strips anything smuggled inside a polyglot file), and the result is saved under a random name outside the public web root — never the name or path the browser sent.
